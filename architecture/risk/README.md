# Master Risk Register

This directory tracks the active Risk Register for `ed-models` using Barry Boehm's Risk Exposure formulation:

$$\text{Risk Exposure (RE)} = \text{Probability (P)} \times \text{Impact (I)}$$

All technical, domain catalog, and operational dependencies are cataloged here.

# Architecture Governance & Engineering Ledger

This directory serves as the authoritative Single Source of Truth (SSoT) for internal technical governance, requirements specifications, architectural trade-offs, and implementation blueprints for `ed-models`.

In alignment with Unified Process (UP) core governance and Rule 5.1 of the Antigravity System Directives, only the canonical engineering disciplines below are maintained within this tree. Customer and operator manuals reside strictly in `docs/` under the Diátaxis framework.

## Subdirectory Taxonomy

* [`risk/`](file:///home/michael/src/github.com/mnaatjes/ed-models/architecture/risk/README.md): Master Risk Register (Boehm-UP Risk Exposure $RE = P \times I$).
* [`use-cases/`](file:///home/michael/src/github.com/mnaatjes/ed-models/architecture/use-cases/README.md): RUP Functional Use-Case Specifications (Cockburn Sea-Level).
* [`adr/`](file:///home/michael/src/github.com/mnaatjes/ed-models/architecture/adr/README.md): Immutable Architectural Decision Records (MADR 3.0).
* [`designs/`](file:///home/michael/src/github.com/mnaatjes/ed-models/architecture/designs/README.md): Software Design Documents (IEEE 1016 / Google Design Docs).
* [`rfcs/`](file:///home/michael/src/github.com/mnaatjes/ed-models/architecture/rfcs/README.md): Collaborative Engineering Proposals.
* [`api/`](file:///home/michael/src/github.com/mnaatjes/ed-models/architecture/api/README.md): Boundary Interface Contracts & Python Protocol Specifications.

# Software Design Documents

This directory houses Software Design Documents (SDDs) adhering to IEEE 1016 and Google Design Document standards.

SDDs are living engineering baselines defining subsystem architectures, data structures, algorithms, and component interactions. Every SDD must declare frontmatter traceability links to its governing ADRs and use cases.

# Architectural Decision Records

This directory maintains immutable Architectural Decision Records (ADRs) conforming to the MADR 3.0 standard.

## Decision Invariants
1. **Immutability:** Once committed and approved, an ADR is permanent and must never be edited to retroactively change historical rationale.
2. **Supersession:** When a decision is changed, author a new sequential ADR that explicitly supersedes the prior record.

# Functional Use-Case Specifications

This directory contains RUP Functional Use-Case Specifications written at Alistair Cockburn's Sea-Level (user-goal level).

Each specification documents user and system interactions, primary success scenarios, extensions, preconditions, and postconditions for `ed-models` capabilities (e.g., token normalization, event hydration, static catalog retrieval).
